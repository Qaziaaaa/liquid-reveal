Liquid Reveal.

A WebGL library that reveals one image through another with a real 2D wave simulation. This is the live demo — move your cursor.

Move your cursor

Start in 30 seconds.

One install, one container, one class. That's the whole library.

01

Install

npm i liquid-reveal

No framework, no build step, zero dependencies. TypeScript types included.

02

Add a container

<div id="hero" style="position:relative;width:100%;height:60vh"></div>
03

Run it

import LiquidReveal from 'liquid-reveal';

const reveal = new LiquidReveal('#hero', {
  base:      'photo.jpg',   // shown first
  chrome:    'chrome.png',  // revealed by the wave
  imgWidth:  1672,          // image size, for the cover crop
  imgHeight: 941,
});

Pass no images and bundled placeholders are used.

One class. That's the API.

Mounts its own canvas, handles pointer input, multi-touch, resize and cleanup for you.
